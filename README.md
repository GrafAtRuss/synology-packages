# Пакеты ИП Ермаков А.С. для Synology

Каталог для Центра пакетов DSM 7. Отсюда ставятся и обновляются все пакеты. Сейчас в каталоге MSSQL Backup. Новый пакет добавляется строкой в [sources.json](sources.json).

## Добавить источник

1. Центр пакетов → **Настройки** → **Источники пакетов** → **Добавить**.
2. Имя: `ИП Ермаков`.
3. Расположение:

```
https://raw.githubusercontent.com/GrafAtRuss/synology-packages/main/packages.json
```

4. **ОК**. Пакеты появятся в разделе **Сообщество**.
5. Уже установленный пакет обновится сам, когда в каталоге будет версия новее. Проверка: Центр пакетов → **Обновить**.

Если DSM пишет, что источник недоступен, укажите запасной адрес:

```
https://cdn.jsdelivr.net/gh/GrafAtRuss/synology-packages@main/packages.json
```

## Как устроено

DSM запрашивает этот адрес и читает `packages.json`: имя, версию, ссылку на `.spk`, контрольную сумму и значки. Файл `.spk` скачивается из релиза своего репозитория.

DS425+ (Intel Celeron J4125, архитектура geminilake) получает пакеты с `arch="noarch"`.

## Добавить ещё один пакет

1. В репозитории пакета публикуется релиз с файлом `.spk`. В `INFO` должны быть `package`, `version` вида `1.2.3-0001`, `displayname`, `description`, `arch="noarch"` (или нужная архитектура).
2. В `sources.json` добавляется `"repo": "GrafAtRuss/имя-репозитория"`.
3. В этом репозитории: Actions → **Update package catalog** → **Run workflow**.

Каталог также обновляется каждый день в 04:17 UTC.
